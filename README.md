# Kalle Kugelrund

Ein Jump and Run fürs Handy im Querformat. Rechts tippen = springen, links tippen = ducken.

Spielen und installieren: https://niklasboeck.github.io/Kalle-Kugelrund/

Auf dem iPhone in Safari öffnen, dann Teilen → „Zum Home-Bildschirm“.

Kalle und die Landschaft sind im Spiel gezeichnet. Gegner, Boden und Geräusche: [Kenney](https://www.kenney.nl) („New Platformer Pack“, „Impact Sounds“, „Interface Sounds“, „Digital Audio“), CC0. Die Musik wird im Spiel erzeugt.
